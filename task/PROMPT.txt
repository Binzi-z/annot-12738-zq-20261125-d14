在原生 Windows 上用 Go 标准库实现安全审计日志重写器。所有数据均为合成。每份输入由多段 JSON 行组成，合成策略按记录类别、样本来源和辖属范围标记允许保留或须抹除的值，规则有撤销水位。两个真实 worker 可以在共享缓冲上限 128 KiB 下并行重写不同批次，读入、解析、重写和待提交容量同时纳入统计。只有整个批次通过保密校验才能让结果可见，末块失败时保留旧结果且没有半截产物。用独立夹具模拟极慢本地写入、拆分超长记录、撤销抢先和末块损坏。核对落盘摘要、实际峰值和原因，数据远大于预算。只需单进程标准库、受控文件失败点和工作区内输出，统一用 `go test -count=1 ./...`。
